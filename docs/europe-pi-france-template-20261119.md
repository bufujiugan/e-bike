# 欧洲 PI 使用 France_1104 版式

用户指定 `France_1104_PI.xlsx` 为欧洲销售与交付的内销、外销 PI 版式，并明确供应商、银行、客户和商品资料沿用每张 PI 的已确认数据。

## 范围与兼容

- 新增 `PI_EUROPE_V1` 渲染版本。具有 `CZECH_PI` 销售入口标识的 PI 草稿及新归档使用同一版式，Excel 和 PDF 共用工作表布局。
- 欧洲入口保存没有销售标识的普通历史草稿时补入 `CZECH_PI`；修订继承原单标识，避免改动原业务归属。
- `PiTemplateService` 负责选择版式，`PiExportArchive` 在确认事务内固化版本，`PiExportWorker` 接受该版本并沿用原导出存储、重试与事务机制。
- 已入队或已归档 PI 保留原渲染版本和文件，不批量重建。国内销售订单及其他 PI 模板不受影响。
- 既有受控模板继续提供卖方、银行与履约配置资料；欧洲 PI 的版式独立固定。没有修改 Controller API、DTO、数据库字段或迁移脚本。

## 版式与数据

- `templates/europe-pi-france.xlsx` 保留原表格的供应商／客户、地址和六列商品结构，清除示例值、公式、图片及历史邮箱超链接；用户原文件不变。
- `PiEuropeDocumentRenderer` 只读取单据快照，填入 PI 编号、日期、版本、币种、双方信息、收款账户、收货地址、商品及条款；Teewing 卖方使用既有品牌图片。
- 原模板中的 KVK、VAT 注册号、SWIFT、买方银行和发货地址目前没有独立快照字段，留空，不从原模板或可变主数据补值。收款账号标签使用 Account，避免把所有账号错误标记成 IBAN。
- 商品净额等于保存行金额减保存行税额，含税金额直接采用保存行金额；VAT 比例由行税额除以折后净额显示，净额为零时避免除零。
- 行折扣随商品说明显示，订单级折扣、税额、运费及其他费用单独列示，总价使用保存的单据总额。正式文件不靠打开 Excel 重算修改成交金额。
- 金额使用数值与两位小数格式；超过 Excel 可靠精度时保留精确文本。所有客户输入按文本写入，不作为公式执行。
- 商品及条款按内容增长；PDF 跨页重复商品表头，页脚含 PI 编号、版本和页码。针对长文本自动增加行高，避免覆盖后续字段。

## 验证

- 新增测试覆盖内销与外销选版、归档冻结、非欧洲与历史版本兼容、模板合并区域、实际快照资料、税额与折扣／费用核对、零净额、超长金额、公式输入安全和 50 行商品 PDF 分页。
- 虚构样例：3 × 100，行折扣 30，行税额 56.70，行净额 270、含税额 326.70；订单折扣 5、订单税额 3、运费 10、其他费用 2，总额 336.70。
- 本地样例与日志位于 `tmp/europe-pi-template-20261119/`。没有创建生产 PI、付款或出库数据。
