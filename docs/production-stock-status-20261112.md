# 生产单车辆库存状态与入库入口

生产任务的 COMPLETED 仅表示四码完成，不能代表车辆已入库。原工作台只展示生产任务状态，入库回执仅存在于当前页面内存，重新打开已入库车辆后仍展示入库表单。

## 修改与兼容

- `ProductionMapper.xml` 的共享任务查询联查当前车辆状态、仓库和库位，新增 `vehicleStatus`、`warehouseName`、`locationName`、`stockInTime`、`stockOutTime` 返回字段。列表、详情、扫码结果使用同一查询；保留原 `status` 的生产状态含义。没有增加逐车查询，没有数据库迁移。
- `ProductionOrderWorkbench.vue` 分开展示生产与库存标识；库存包括待入库、已入库、已出库及返工、售后、报废。已入库显示当前仓库／库位及最近入库时间；已出库显示流转时间；只有完成生产且车辆状态为组装完成时才展示入库表单。
- 刷新本单、刷新车辆列表与入库操作结束后重新获取选中车辆，重新选择也读取服务端状态。未知状态、读取失败时关闭入库入口。刷新期间阻止提交，保持请求版本校验，避免旧请求覆盖新选择。
- 打印后的引导根据库存状态显示“办理入库”或“查看库存状态”。四码进度明确说明与入库进度不同。

接口为只新增字段的兼容扩展，现有客户端忽略新增字段即可；后端入库事务、最终状态验证、权限及幂等保护不变。回退需同步回退前后端，否则新前端连接旧后端会将缺少库存字段的车辆显示为待核实并阻止入库。
