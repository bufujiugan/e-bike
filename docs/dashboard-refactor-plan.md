## 数据口径

- 顶部显示今日组装、物理库存、今日入库、失败扫码记录，不将失败记录条数伪装成异常任务数。
- 今日任务从原任务查询接口按当日日期过滤，最多读取前 50 条；流程、工位和环图均标明对应范围，不遍历分页伪装全量统计。
- 四工位对应车架、电机、电池、仪表的真实扫码完成情况。没有产线实体、节拍、直通率数据，不使用 A/B/C/D 产线假数。

- 保留原首页全部汇总指标、整车状态、快捷入口和最近操作，放入可展开的补充面板。
- 不新增数据库数据、不改表、不改接口、参数定义、权限、URL 或业务写操作。
