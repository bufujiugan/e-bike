## 当前版本：2026-10-20 工作空间导航

本节替代下方历史版本的顶部管理员卡片方案，保留历史记录用于追溯。

- 修改 `Sidebar.vue`：顶部展示 BIKE 品牌和工作空间名称；移除侧栏用户信息，退出登录固定在独立底部区域。分组与菜单采用统一图标、字号、缩进和纯蓝色选中背景，保留响应式图标栏和滚动区。
- 修改 `TopHeader.vue`：白色顶栏左侧为面包屑、页面标题及原有权限功能搜索，右侧为刷新、通知和账号入口。刷新执行当前页面重载；通知浮层说明现有业务通知查看方式，只有售后权限用户才能看到售后入口，不虚构未读数量或全局通知数据。

- 修改 `AppLayout.vue`：将设置与退出事件从顶栏接入原有应用流程。修改 `AppIcon.vue`：增加与现有线条体系一致的通知图标。
- 未修改业务页面、菜单配置、权限过滤或 API。沿用 `clamp()` 响应式侧栏宽度与刷新后的折叠状态恢复。

## 顶部用户区与响应式收缩

根据最终参考图和补充要求，当前版本继续调整为：

- `AccountMenu.vue` 将头像、`admin` 和角色放到侧栏顶部，整个用户区域可点击；浮层继续复用“设置”和“退出登录”，卡片内部不放独立箭头。
- `Sidebar.vue` 在侧栏与内容区边界独立放置双箭头按钮；展开状态显示完整菜单，收起状态只显示图标和头像。
- `AppLayout.vue` 使用 `bike_sidebar_collapsed` 保存用户选择，刷新和直接打开子路由后仍恢复侧栏状态。
- `tokens.css` 使用 `clamp()` 定义宽度：展开为 `clamp(13.75rem, 15.3vw, 15.25rem)`，收起为 `clamp(3.625rem, 4.6vw, 4.25rem)`；历史移动端 `.sidebar` 规则也统一引用该变量，不再保留固定 `66px`。
- `smart-manufacturing.css` 同步侧栏和内容区宽度过渡，并为 `100dvh` 增加 `100vh` 兼容兜底，确保旧浏览器中菜单仍在视口内独立滚动。
- `TopHeader.vue` 移除重复用户信息，只保留功能搜索、面包屑和最近加载时间。
