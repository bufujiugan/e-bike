# PI受控卖方资料与历史版本

V46为已发布模板增加卖方国家/地区、联系人、电话和Email，字段为sellerCountry、sellerContactName、sellerPhone、sellerEmail。新模板使用DOMESTIC_V3或EXPORT_V3，四项均必填，Email校验格式；原sellerContact保留为可选补充联系方式。发布仍需内部PI_TEMPLATE_MANAGE，版本唯一、不可覆盖，资料和审计同事务保存。

业务员选择模板后，卖方名称、地址、国家、联系人、电话、Email、补充联系方式及银行资料全部只读带入。后端保存和确认逐项核对所选版本，直接请求改写也拒绝。客户资料自动带入只填买方缺失字段，不会覆盖卖方。模板发布新版本不刷新已保存PI，需在草稿中明确重新选用；已确认PI须创建商业修订。

历史模板新字段为NULL，不从旧联系方式或地址猜测国家、电话和Email。V1/V2模板保持列表可读，原快照、原发布人/时间、银行资料均不改变；新建或修改草稿及确认时须选择完整V3模板。历史修订草稿仍能克隆原资料，发布前重新选用新版本。升级后管理员需核对真实卖方资料并发布新版本，系统不植入示例银行或联系人。

归档队列按模板固定PI_V1/PI_V2/PI_V3；已有任务无版本字段时仍走PI_V1。V3仅在对应版本增加结构化卖方行，旧V2重试不增加新行，旧V1仍用冻结渲染器。草稿预览也按所选模板版本渲染。两份归档各自成功后固定，后续模板、收款、物流及修订变化不会重生成替换它们。

批次36的检查覆盖四字段防篡改、不完整发布/错误Email/贸易版式拒绝、可选补充联系方式、V38旧模板经V46升级不猜历史、V2归档仍可生成、V3两格式和新版本独立性。真实HTTP另验证正常销售/财务/仓库/客户流程和模板变化后的原PI快照及归档SHA256。预览使用虚构样例，只证明布局和字段，不替代业务正式样单签认。
