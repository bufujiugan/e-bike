# 权限模型

库位新增、编辑和状态维护属于超级管理员写权限；Web 业务员可凭 `MASTER_READ` 只读库位列表，PDA 入库只读取启用仓库和库位。

权限模型为：

```text
用户 -> 角色 -> 工位/功能权限 -> 数据范围
```

首期数据库已建立用户、角色、权限、用户角色和角色权限表，以及 PDA 工位表。当前 JWT 会从数据库加载用户角色、权限和工位类型；开发管理员配置账号作为兼容兜底。`WEB_AGENT` 账号必须绑定 `agent_id`，代理商锁库列表、释放、转订单、模块订单查询和授权车型列表由后端强制限定代理商范围；代理商不能访问客户、供应商、代理商、仓库和系统配置基础资料。超级管理员可通过代理商管理路由查看和维护全量数据。组装、入库、出库（含撤销）和返工 Service 会校验绑定工位。系统管理写接口、整车建档和二维码重新生成均要求 `SUPER_ADMIN`，系统配置读写接口仅超级管理员可访问。
