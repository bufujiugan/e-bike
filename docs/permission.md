# 权限模型

库位新增、编辑和状态维护属于超级管理员写权限；Web 业务员可凭 `MASTER_READ` 只读库位列表，PDA 入库只读取启用仓库和库位。

权限模型为：

```text
用户 -> 角色 -> 工位/功能权限 -> 数据范围
```

## 登记表岗位的默认菜单

管理员在「用户管理」先选择账号类型，再分配岗位角色。Web 菜单按生效权限展示，PDA 作业按权限和绑定工位展示。在「角色权限」可以查看默认权限并按业务需要调整。

| 后台岗位 | 角色编码 | 默认可用范围 |
| --- | --- | --- |
| 系统管理员 | `SUPER_ADMIN` | 用户、角色、工位、系统配置与业务模块 |
| 负责人／管理层 | `MANAGEMENT_VIEWER` | 运营概览、库存、出入库记录、销售订单、PI 与履约，只读 |
| 仓库主管 | `WAREHOUSE_SUPERVISOR` | 库存、出入库记录和追溯 |
| 文员／单据员 | `DOCUMENT_CLERK` | 维护零部件、查询基础资料和出入库记录 |
| 财务人员 | `FINANCE_VIEWER` | 查看授权客户的销售订单、PI 收款与凭证，导出 PI 报表 |
| 业务管理员 | `BUSINESS_MANAGER` | 全部客户的订单、PI、库存、生产管理和售后等业务模块。系统管理、收款确认和撤回、发货放行由对应授权控制 |
| 业务员 | `BUSINESS_STAFF` | 库存及锁库、授权客户的订单、PI 与物流跟进 |

| PDA 岗位 | 角色编码 | 工位类型 | 默认作业入口 |
| --- | --- | --- | --- |
| 收货／入库人员 | `PDA_RECEIVING` | `STOCK_IN` | 扫码入库、追溯核对 |
| 拣货／出库人员 | `PDA_PICKING` | `STOCK_OUT` | 订单出库、PI 出库、追溯核对 |
| 库存查询人员 | `PDA_INVENTORY_VIEWER` | `STOCK_LOOKUP` | 扫描整车聚合码或车架 SN，查询在库整车的车型、仓库和库位 |
| 盘点人员 | `PDA_STOCKTAKE` | 待配置 | 岗位预置为停用，等待盘点流程 |
| 移库／上架人员 | `PDA_RELOCATION` | 待配置 | 岗位预置为停用，等待移库流程 |

现有出入库为扫码执行流程，尚缺后台制单和独立审核环节。PDA 库存查询按整车编码精确检索，工位类型仅用于区分作业权限，未用于限定仓库。迁移只添加角色和权限配置，人员与账号的对应关系由系统管理员在用户管理维护。

首期数据库已建立用户、角色、权限、用户角色和角色权限表，以及 PDA 工位表。当前 JWT 会从数据库加载用户角色、权限和工位类型；开发管理员配置账号作为兼容兜底。`WEB_AGENT` 账号必须绑定 `agent_id`，代理商锁库列表、释放、转订单、模块订单查询和授权车型列表由后端强制限定代理商范围；代理商不能访问客户、供应商、代理商、仓库和系统配置基础资料。超级管理员可通过代理商管理路由查看和维护全量数据。组装、入库、出库（含撤销）和返工 Service 会校验绑定工位。系统管理写接口、整车建档和二维码重新生成均要求 `SUPER_ADMIN`，系统配置读写接口仅超级管理员可访问。
