# 独立项目整理与 GitHub 归档任务

目标仓库：https://github.com/bufujiugan/e-bike 。整理日期：2026-09-18。

## 范围与方案

保留现有业务代码、原始需求、会议材料、沟通成果、原型及验收证据；提供克隆后可操作的独立启动流程。归档不代表补齐尚未交付的生产页面或 PI/售后模块。

| 文件/目录 | 整理内容及原因 |
| --- | --- |
| `README.md` | 完整介绍、功能边界、依赖、快速启动、目录、文档入口、验证与排障 |
| `docs/README.md`、`docs/communication/` | 资料索引、需求决策、按日期脱敏的需求沟通记录 |
| `docs/deployment.md`、`deploy/`、`compose.yaml` | 本地/容器独立部署、数据库初始化、反向代理、备份恢复 |
| `.env.example`、`tools/start-local.ps1` | 显式配置、随机开发凭据及便携的启动入口 |
| `.gitignore`、`.gitattributes`、`.github/workflows/` | 排除运行数据与凭据，统一文本，持续构建 |
| `docs/archive-manifest.json` | 文件分类、来源与 SHA-256，便于交接核对 |
| 原部署/核查文档 | 修正本机绝对链接，标注历史验证日期与本机依赖 |

不修改公共 API、DTO、业务事务和 V1–V16 迁移内容。部署使用新的独立数据库；既有本机数据库、日志、缓存不删除、不上传。容器数据库和附件分别使用持久卷；停机保留数据，升级先备份，回滚遵守生产隔离/预占约束。
