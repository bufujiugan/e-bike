## 修改范围及兼容方案

后端新增 `production` 业务模块及对应 Mapper.xml；组装、出入库及返工仅增加生产占用和隔离保护。新增 `/api/production/**`，不替换原公共 DTO 或改变整车状态枚举。Web/H5 新增独立生产组件，保留原仓库和订单页面。

数据库新增生产专用表，原表及历史数据保留。DDL 与业务 SQL 均存放在 Mapper.xml，Java 版本迁移只执行 XML 中的结构语句，满足现有 SQL 放置规范。生产与开发共用新增 Java 迁移。

## 一致性

生产任务扫码、部件预占、四码绑定、聚合码及首打任务同事务完成。生产写入采用数据库互斥行及业务唯一约束，低并发下优先保证正确性。旧组装/出入库/换件入口使用同一保护。打印通过持久化队列执行，与设备故障隔离；不把提交给打印机等同于实物正常出纸。上传完成并校验后才绑定附件，文件失败不能记录为可用证据。

回退需停用新生产写入口、保留新增表和已产生的任务/占用；不可把旧程序直接恢复为可绕过占用和隔离的写入口。已有数据库脚本不修改。

## 实物与云配置边界

打印设备型号、纸张尺寸和原始标签样稿尚未提供；先提供两种可配置版式及 Windows 系统打印驱动接入。自动提交到系统打印队列可验证，真实出纸/扫码/纸卷耗材由用户现场验收。

图片已提供受保护本地存储及 COS 可配置接入；本地存储已实测，COS 尚未使用实际账号联调。云账号、存储桶及设备账号使用外部配置，不写入源码或文档。

## 验证重点

24 种扫描顺序；车架最后扫描；重复扫描；并发抢同一部件；扫码失败不丢前项；刷新恢复；重新登录与账号权限；取消释放；四码完成重复请求不二次绑定；标签首打与补打；隔离阻止组装/入库/出库；不良旧件换出后不能复用；历史追溯；图片访问鉴权。
