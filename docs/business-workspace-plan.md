# 连续业务办理改造

## 目标与边界

将商品配置、生产工单、标签打印、库存锁定与订单履约集中到业务办理工作台。保留原列表和权限，使用真实接口，不修改业务状态机、事务、数据库和历史数据。生产与销售通过 SKU 库存衔接，不推断工单与订单一对一关系。

## 实施清单

- [ ] 新增业务办理工作台，流程页签、选中 SKU 上下文、权限过滤与刷新恢复。
- [ ] 工单详情集中查看四码、单车打印、库存及出入库追溯。
- [ ] SKU 库存支持带入商品，锁定结果可直接转订单。
- [ ] 订单办理详情集中展示来源锁定、客户、履约进度、出库车辆和关联 PI 入口；支持原地确认。
- [ ] 转订单成功直接打开新单详情，现有销售列表共用该详情。
- [ ] 前端构建、真实只读接口、桌面与手机浏览器验收。

## 影响与兼容

修改 App.vue 的菜单、详情入口和转单成功回调；ProductionManager.vue 增加可选上下文及单车履历；SkuInventoryPanel.vue 增加可选商品条件和转单事件；PiWorkspace.vue 增加可选查询条件。新增工作台与订单办理组件。所有新增组件参数均可选，旧入口仍可独立使用。移除新入口与新增组件引用即可回退界面，数据库无需回滚。

写操作沿用原后端鉴权、事务和幂等键。页面切换不自动执行确认、打印、锁定、入库或出库；接口失败保留错误并提供重试，不推断成功状态。
