# PI Excel 参考版式调整

## 范围

参考用户提供的 `wireless controller PI.xlsx`：英文标题、左右买卖方资料、蓝色单据信息栏、五列商品表、Net total、贸易及付款条款、银行账户资料。A4 纵向打印，按一页宽度适配，多商品可跨页并重复表头。

仅提取参考文件顶部的 TEEWING Logo，存放于 `bike-server/src/main/resources/pi/teewing-logo.png`。卖方名称属于 Teewing 时展示 Logo。两张底部签名图片不进入资源或导出文件；SKU 商品图片按原快照继续展示。

## 实现和兼容

- `PiReferenceExcelRenderer` 负责新 Excel 版式，使用保存的 `PiView`、`PiDocumentSnapshot` 和商品图片，不读取客户或银行主数据。
- `PiTemplateService.renderVersion` 为当前内外销 V3 业务模板选择 `PI_V4` 渲染版本，`PiDocumentService` 路由新 Excel 渲染器，`PiExportWorker` 接受该版本。模板管理 API 和 DTO 不变。
- 已入队的 `PI_V1`、`PI_V2`、`PI_V3` 快照保留原渲染逻辑，已归档文件继续原字节下载。新版本 PDF 保留 V3 的内容和版式。
- 异步任务仍以入队快照固定版本，不重建或替换历史导出；事务、租约、库存和付款流程不变。
- 商品、折扣、税额、运费、其他费用和总额保持保存值。五列展示不重复计入折扣、税额。超出 Excel 可靠精度的金额仍保留十进制文本及批注，客户文本不作为公式执行。
- 长地址、商品说明和条款分行并动态扩展，避免单行高度上限导致文字丢失。

## 数据边界

参考中的客户、银行账号等交易信息不作为系统默认数据。当前单据快照没有独立的订单编号、Bank Address、SWIFT Code、Bank Code、Branch Code 字段，因此订单编号留空，不把数据库 ID 当作订单编号，也不硬编码参考中的银行信息。现有账号、户名、银行名称使用单据自身数据。
