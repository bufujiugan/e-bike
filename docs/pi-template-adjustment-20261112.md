# PI 模板调整与新版本保存

本次提交包含工作区剩余的全部代码修改，涉及三个前端组件。

- `PiTemplates.vue`：从已发布模板回填卖方、默认银行和版式，自动生成可修改的新版本号，以现有发布接口保存新版本；保留旧版本及历史单据。提供独立编辑弹窗、保存状态和表单错误提示，移动端使用单列布局。
- `PiTemplatePicker.vue`：分开模板选择禁用与模板管理禁用，避免履约配置固定模板后无法进入管理。新增可选属性 `manageDisabled`，保持原调用兼容。
- `PiWorkspace.vue`：连接模板管理与单据选择；绑定履约配置时，提示复制履约配置的新版本并选用新模板，再返回单据选择配置。

调用链为 PI 工作台／模板选择器 → 模板管理 → 原 `publishTemplate` API。无后端接口、数据库结构或事务修改。原发布接口负责版本保存，前端使用保存状态防止重复提交。既有模板和单据快照保留，不自动替换已绑定履约配置。

验证：`npm run build` 通过（含 `vue-tsc --noEmit`）；浏览器验证真实模板字段回填、模板编码固定、新版本号生成；390 像素宽度无页面横向溢出；拦截模拟发布请求验证保存成功流程及提交内容，未创建线上测试模板。
