# PI 本机草稿（2026-11-10）

## 行为

- 新建 PI、编辑已有 PI 草稿、从 SKU 锁定生成 PI 均可保留未填完整的内容。
- 输入变更自动保存；所有步骤均有“保存本机草稿”。关闭时提供“继续填写”“放弃并离开”“保存草稿并离开”。
- PI 页面显示本机草稿列表，可继续填写或单独删除。新建另一份 PI 不覆盖此前草稿。
- 保存表单、商品数量和金额原文、来源订单/锁定、当前步骤、转换请求幂等标识；恢复时重新加载基础资料和履约配置。
- 正式保存 PI 继续使用现有完整校验和接口；成功后清除对应本机草稿，失败时保留。
- 本机草稿按当前站点、浏览器和账号隔离，不支持跨浏览器或跨设备同步。清理站点存储会移除草稿；页面已明确提示。

## 实现与影响

- `bike-web/src/components/PiWorkspace.vue`：自动保存、退出确认、恢复入口、保存状态和失败处理；恢复期间阻止客户关联 watcher 清空来源订单及锁定；关闭时使未完成的资料请求失效。
- `bike-web/src/pi-local-drafts.ts`：带版本的浏览器存储、结构校验、账号隔离及逐份删除。金额保持字符串，临时清空的日期、数量也可保存。
- `bike-web/src/styles/pi-draft.css`：草稿列表和状态栏，窄屏操作按钮换行。
- `tools/acceptance/pi-local-drafts.test.mjs`：存储行为回归测试。
- 不修改 Controller API、DTO、数据库、服务端事务、库存逻辑或发布流程。

## 一致性与失败处理

- 未修改的空表单不自动生成草稿；手动保存可保留空草稿。
- 存储失败显示错误；“保存草稿并离开”失败时保持表单打开。刷新/关闭浏览器时尝试补存，失败则触发浏览器离开提示。
- 浏览器存储版本不兼容或内容损坏时保留原始内容并提示，不静默删除。
- 写入和删除前比对读取时的存储快照，已检测到其他页面修改时不覆盖；用户可“另存为新草稿”保留自己的输入。该比对不是跨标签页的事务锁。
- 恢复已有 PI 和正式更新前读取服务器状态及 `updatedAt`；原 PI 已变化时提示核对，保留本机内容。前端检查不替代服务端原子并发控制。
- 恢复来源锁定后，正式转换仍由现有服务端校验库存、有效期及幂等请求。
