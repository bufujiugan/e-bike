# 历史交付材料制作脚本

这里保留客户沟通 PDF、售后增补 PDF、原型打包和截图的历史制作源代码，原始成果见 `output/pdf`、`output/prototype` 和 `output/playwright/ebike-hifi`。

这些是历史辅助脚本，不是业务系统启动依赖。部分脚本保留原作者 Windows 路径、字体路径、临时目录及浏览器环境，重建材料前应检查并改为当前路径；需要 ReportLab、PDF 工具或 Playwright 等额外依赖。现成 PDF/HTML/PNG 可直接查看，不必运行制作脚本。

不要把其中的原型交互校验作为生产业务验收，也不要向真实业务数据库执行历史验收脚本。
