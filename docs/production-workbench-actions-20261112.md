# 生产单操作样式和车辆总码便捷操作

## 变更范围

仅修改 bike-web/src/components/ProductionOrderWorkbench.vue。

- 扫码、标签打印和库存环节使用相同操作卡片、主按钮尺寸及箭头图标；手机上按钮铺满卡片。
- 当前车辆总码旁增加“复制总码”，兼容 HTTPS/localhost Clipboard API 和线上 HTTP 页面复制。
- 入库字段更名为“入库车辆总码”，选择车辆、刷新详情或扫码生成总码时自动带入；仍允许扫描标签替换。
- 提交时保留总码与当前车辆一致性检查、库存状态检查及原有权限控制。

自动带入只是减少输入，不代表已经核对实物。操作员仍需核对实际车辆、仓库和库位。

## 验证

- npm run build 通过，包含 vue-tsc；保留现有构建大包提示。
- 浏览器模拟待入库状态，检查两台车切换、刷新和返回时总码同步。
- 三个主按钮实测均为 190×36 px、8 px 圆角。
- Clipboard API 和 HTTP 兼容复制均获取当前总码，临时复制元素清理正常。
- 手动填写错误总码被页面拦截，业务写请求为 0。
- 流转记录弹窗正常打开，1440 px 桌面和 390 px 手机布局经过截图检查。

不修改后端接口、数据库字段或库存规则；本次仅发布 web，沿用当前后端与 PDA。可通过恢复上一版本入口回退页面。
