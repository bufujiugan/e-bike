# 列表 ID 展示（2026-11-10）

## 展示范围

- 28 个通用模块：供应商、零部件、车型、客户、仓库库位、用户、角色、工位、车辆、订单、出入库、库存锁定、返工、日志等。
- 独立列表：客户授权、上传核对、生产工单/SKU/扫码失败/异常/打印、PI/模板/履约配置/收款/物流/附件/修订、售后等。
- 普通记录显示 ID；库存汇总显示真实的 SKU、车型、仓库、库位 ID；订单明细同时显示订单与明细 ID。上传记录使用其实际主键 objectKey。
- 关联订单、有效出库车辆及售后发运/退回记录同步补充相应 ID。未保存的行没有数据库 ID 时显示“—”。

## 兼容性

- `ModuleServiceImpl` 在原 `columns` 和行数组末尾追加 ID，`ModuleList.vue` 只调整展示顺序。原有编辑、详情和状态操作使用的数组下标不变。
- `ModuleMapper.xml` 返回对应主键；`ProductionMapper.xml` 补充库存维度 ID 与隔离零件 ID。
- `RecordIdColumn.vue` 统一独立表格 ID 列，支持长字符串换行和复制。
- Controller、DTO 定义、数据库结构与业务写入流程不变。原有权限和数据范围过滤保留，无迁移、缓存、事务或异步流程变更。
- 通用接口 ID 由服务端转为字符串，保留大整数精度；独立接口沿用原有字段类型。
- 发布需同步更新前后端。回滚此次展示与查询增列改动即可，不涉及数据回滚；应保留同工作区的 PI 本机草稿改动。
