# 销售入口与单据模板绑定

日期：2026-11-19。代码已提交 GitHub；最终应用版本 `b029be0` 于 17:25:03 部署生产。上线及修正记录见 `docs/deployment-sales-routing-20261119.md`。

## 业务对应关系

| 入口 | 单据 | 用户指定参考文件 | 实现 |
| --- | --- | --- | --- |
| 销售订单 → 内销 | 购销合同 Excel | `10.23金轮信德-广州塔威 购销合同(1).xlsx` | `OrderContractWorkbook`，沿用该文件的脱敏模板资源 `templates/domestic-purchase-contract.xlsx` |
| 销售订单 → 外销 | PI Excel / PDF | `260728英国builtPI.xlsx` | `PiTemplateService` 按 `CHINA_SALES` 固定 `PI_V5`，使用现有五列参考发票渲染器 |
| 欧洲销售与交付 → 内销 / 外销 | PI Excel / PDF | `France_1104_PI.xlsx` | 按 `CZECH_PI` 固定 `PI_EUROPE_V1`，沿用 `templates/europe-pi-france.xlsx` |

国内外销此前会随已发布模板的 `layoutCode` 切到标准明细表，本次固定销售场景优先级。英国参考版式为现有程序化实现：保留双方资料、蓝色单号日期栏、五列商品和银行资料布局，商品描述列加宽并支持多行及费用明细。不会将参考文件里的历史客户、价格、银行账号和签名复制进新单。

卖方、银行及交易条款继续使用受控模板和本单快照。原始三份文件未修改。国内购销合同与 France 模板资源的合并区分别与原文件一致（44、37 处）。

## 国内内销及历史记录

- 普通订单办理页突出“生成购销合同”，不再显示无关联的 PI 入口或要求 PI 放行的提示。
- 已有 PI 关联时保留“查看已关联 PI 与履约”，该嵌入工作台不再提供新建 PI 入口。
- 订单关联的全部 PI 版本均为 `DOMESTIC`、明确国内出货、且无欧洲或其他销售入口标识时，可生成国内购销合同。
- 外销、欧洲、缺失出货属性或关联版本归属矛盾的订单不能通过该出口生成国内合同，提示核对 PI 归属。不会根据客户名称或币种猜测。
- 导出合同不修改订单、PI、收款或库存；历史 PI 的确认、到账和放行条件仍有效。

## 接口与一致性

- 合同准备响应新增 `hasLinkedPi`，保留原 Java 三参数构造器。
- 订单详情 `SalesOrderView` 新增可空 `hasLinkedPi`，用于保留只读账号、代理商查看已关联 PI 的能力；不放宽原客户范围或权限。
- 原 API 路径、请求字段和数据库结构不变，前端按新增字段显示入口。合同准备及导出仍需 `ORDER_READ`、`ORDER_WRITE` 和内部账号。
- 合同使用只读、可重复读事务核对来源、订单快照、数量、需方和价格；关联查询通过 Mapper.xml 执行，适用性规则在 ServiceImpl 中判定。
- PI 草稿预览及新归档采用同一场景选择逻辑。已归档或已入队文件保持原渲染版本，重试不会替换历史快照。
- 无数据库迁移、缓存、MQ、定时任务调整。发布时先兼容后端再前端；回退应用代码即可，无需恢复数据库或改写已归档文件。
