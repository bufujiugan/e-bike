## SKU Toolbar

列表右上角依次为：搜索 SKU、车型或商品名称 → 刷新 → 导入 SKU → 新增 SKU。新增为蓝色主按钮，刷新与导入为次要按钮。导入和新增继续受 `canManage` 权限控制。主体中不再常驻模板下载、文件选择和导入区域。

## 导入 SKU

640px 弹窗包含说明、模板下载卡片、拖拽选文件区、文件名与大小、删除/替换、导入结果和逐行错误。只选文件不自动上传；点击开始后提交。忙碌时防止重复操作和关闭。全部成功关闭并刷新；部分失败或请求失败保留弹窗和文件，展示后端真实原因；关闭后清空状态。

## 模板下载

沿用 `GET /api/production/skus/import-template` 获取真实 Excel，下载期间显示 Loading；不会另造前端模板，下载不关闭弹窗。Blob 类型的错误响应按 JSON 消息解析。

## 文件上传

沿用 `POST /api/production/skus/import`，FormData 键为 `file`。单文件 XLSX/XLS，非空且不超过 10MB；后台最多 5000 行。没有增加 CSV、额外 MIME 限制或改动认证。

商品图片继续使用原 SKU 附件接口。最新补查增加上传期间的保存/关闭保护；成功与失败均由真实上传组件反馈，保留失败文件重试入口。

## 业务逻辑

SKU UI 专项没有修改 API、权限规则、业务数据结构或路由。列表仍取自 `GET /api/production/skus`；因该接口返回完整数据，搜索及 20/50/100 条分页在客户端对真实列表执行，没有伪造后端分页或 SKU 记录。

验收环境中的记录由真实接口和后台管理，但使用隔离验收库，不是正式客户生产库。验收新增的三条明确标识 SKU 已停用，审计与附件保留。未清理发货后的业务附件，也未把历史未登记对象纳入自动删除。
