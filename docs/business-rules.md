# 业务规则

## 整车和部件

- `frame_sn` 全系统唯一，是整车业务主 ID。
- 电机、电池、仪表是整车子部件，绑定后不得同时绑定第二台整车。
- 四码绑定成功后生成整车总二维码；二维码用于识别和查询，不能替代 `frame_sn`。
- 返工换件只能失效旧绑定并新增绑定记录，不能覆盖历史数据。

## 状态和出入库

- 整车状态按 `待组装 -> 组装完成 -> 已入库 -> 已出库` 正常流转。
- 入库只能在 PDA 入库页面执行，且整车必须为组装完成。
- 普通出库必须先选择客户和订单；后端逐台校验接口也拒绝缺少任一上下文的二维码，再扫描并批量确认已入库整车。

## 代理商锁库存

- 第一版只锁定整车车型数量，不锁定零部件和具体车辆 SN。
- 可用库存按车型扣除隔离与当前有效承诺，详见下方销售占用规则。
- 锁库不绑定仓库、库位或具体车辆 SN；库存明细接口按车型汇总锁库量，并按稳定的仓库/库位顺序将锁定量分摊到展示行，确保同一车型的明细行不会重复累计。该分摊仅用于展示，锁库释放、过期和转订单仍以车型锁定记录为准。
- 锁定、释放、过期和转订单都必须可审计。

## 销售占用补充（V20–V22）

可售量 = 物理在库 - 质量隔离 - 有效临时锁定剩余量 - 有效来源订单未发量，下限为0。接口 lockedQty 为临时锁定 temporaryLockedQty 与订单占用 orderReservedQty 之和；shortageQty 表示承诺超过合格在库的缺口。总览先按车型计算再合计，不用其他车型可售库存抵消缺口。即使已无在库车辆，仍展示未履行的有效承诺。

锁定转订单不减少物理库存，不增加可售量；实际出库减少物理量和本订单未发占用；受控撤销出库恢复两者。普通订单不能挤占已有承诺。来源占用到期后，确认或出库被拒绝，需重新竞争库存；到期订单不会自动删除或抹去历史。SHIPPED来源订单允许续占用（未发量为0），以支持占用到期后的受控撤销出库。

取消未发订单释放订单占用；部分发货只能关闭剩余，已发历史保留。关闭订单不能撤销出库重新打开，操作前须核对。来源订单不可直接修改车型/数量，需取消后重新办理。

锁定只承诺车型数量，不指定仓库/车辆。库存列表的库位分摊属于展示规则，不代表实体预留：按仓库/库位顺序先全局分摊，再应用仓库筛选，筛选不重新分配全车型承诺。

旧版本只有converted_qty、没有真实订单的转换记录不自动伪造关联，切换前须人工对账。V21新备注字段不从历史操作日志盲目回填。


V22生产管理权限只作为可分配能力注册，不默认改变角色范围。生产主管可由管理员授予 PRODUCTION_MANAGE 后维护SKU、标签、生产图片、异常解除和旧件复检；扫码、入库、出库和打印仍分别受功能权限与工位约束。


历史转换对账必须人工完成：旧版本只有 `converted_qty` 的锁定记录不能推断客户或订单。内部 Web 可通过 `/api/inventory-locks/legacy-conversions` 分页查看没有真实订单占用关联的记录，核对业务凭证后再处理；查询本身为只读，不会自动补单或改变库存。

## PI 收款保留来源订单占用（V25）

来源订单占用分为 `TIMED`（限时）、`PAID`（收款达标保留，待履约或人工关闭）和 `RELEASED`（主动释放）。PI 已确认且数据库当前时刻尚未到达来源占用截止时间时，累计实际收款达到该 PI 的 `depositRequiredAmount` 才转为 `PAID`；定金门槛为零时在确认 PI 时执行同样检查。保留的是当前来源订单的车型剩余数量，不增加物理库存，也不构成 SKU 级锁库存。

截止时刻及之后登记收款仍保存真实财务事实，但不会复活失效的占用；倒填到账日期也不能改变这个判断。此时返回 `EXPIRED_REQUIRES_REACQUIRE`，业务员须明确重新核对库存并办理续占用；库存不足时拒绝重新占用，已经保存的收款不受影响。重复收款请求不重复扣记款项，也不重新尝试保留库存。旧记录升级后全部沿用 `TIMED`，不按照历史收款自动恢复占用。

`PAID` 保留原始截止时间用于追溯，不将其改成遥远日期；有效数量按原占用量减已出库量计算。全部出库后数量为零，仍保留其方式，以便受控撤销出库时同步恢复物理量和订单承诺；对 `PAID` 再请求续期不会改回限时或延长日期。取消订单、取消无款无出库的 PI、关闭部分发货订单的剩余数量会主动释放，已释放记录不能通过续期接口重新打开。

收款保留、重新占用、到期审计和其他库存写入共用库存互斥锁。收款门槛达成不代替发货门槛和人工放行；来源占用已到期或释放时，即使发货款已满足也拒绝放行。代理商只能看到通用有效状态，不能从返回字段读取收款保留方式、保留时间或收款凭证。
