# 业务规则

## 整车和部件

- `frame_sn` 全系统唯一，是整车业务主 ID。
- 电机、电池、仪表是整车子部件，绑定后不得同时绑定第二台整车。
- 四码绑定成功后生成整车总二维码；二维码用于识别和查询，不能替代 `frame_sn`。
- 返工换件只能失效旧绑定并新增绑定记录，不能覆盖历史数据。

## 状态和出入库

- 整车状态按 `待组装 -> 组装完成 -> 已入库 -> 已出库` 正常流转。
- 入库只能在 PDA 入库页面执行，且整车必须为组装完成。
- 普通出库必须先选择客户和订单；后端逐台校验接口也拒绝缺少任一上下文的二维码，再扫描并批量确认已入库整车。

## 代理商锁库存

- 第一版只锁定整车车型数量，不锁定零部件和具体车辆 SN。
- 可用库存等于物理库存减去当前有效锁定库存。
- 锁库不绑定仓库、库位或具体车辆 SN；库存明细接口按车型汇总锁库量，并按稳定的仓库/库位顺序将锁定量分摊到展示行，确保同一车型的明细行不会重复累计。该分摊仅用于展示，锁库释放、过期和转订单仍以车型锁定记录为准。
- 锁定、释放、过期和转订单都必须可审计。
