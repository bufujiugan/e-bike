# 第一轮测试范围

## 已覆盖目标

- 登录参数校验。
- 正确账号密码返回 JWT。
- 错误账号密码返回业务错误码。
- 未认证请求被 Spring Security 拒绝。

## 后续核心测试

- 四码正常绑定和重复部件并发绑定。
- 错误类型扫码和不可用部件。
- 状态机非法跳转。
- 入库、出库和撤销操作事务回滚。
- 代理商锁库存超卖、过期和并发竞争。
- Web/PDA/代理商数据权限隔离。

## 已补充的运行态验收

- Web Dashboard、整车档案页面：数据库数据渲染、模块请求和路由跳转。
- H5 工位登录、组装页和移动端出库顺序：未选择客户/订单时禁止扫码输入。
- H5 出库逐台扫码携带订单上下文，后端拒绝车型不匹配车辆并实时展示订单数量、已出库数量和本次剩余数量。
- 后端出库逐台校验拒绝缺少客户或订单的请求，即使车辆已经入库也不能仅凭总二维码进入可出库状态。
- 整车二维码重新生成：业务员调用被拒绝，超级管理员可重新生成并写入版本审计。
- 返工审计链路：`PART_UNBIND`、`PART_BIND`、`REWORK` 日志及追溯事件部件信息。
- Service 层未认证边界：无 Spring Security 上下文时，权限和工位校验统一返回 `UNAUTHORIZED`，不依赖 Controller 路由拦截。
- 数据库唯一约束并发绑定冲突会转换为明确的 `PART_ALREADY_BOUND`，不会继续写入整车完成状态。
- 代理商列表和释放操作按 JWT 中的 `agent_id` 隔离，代理商 A 不能读取或释放代理商 B 的锁库。
- 连续 5 次登录失败后账号进入短期锁定窗口。
- 零部件反向追溯保留关联整车的入库、出库和返工记录。
- 代理商锁库和采购意向创建可省略 `agentId`，服务端使用 JWT 代理商范围；超级管理员缺少 `agentId` 时明确返回业务错误。

## PDA 交互验收

- 组装四码校验请求包含 `frameSn`，与后端 DTO 契约一致。
- 组装步骤校验成功后自动聚焦下一扫码字段；扫码枪回车可触发校验。
- 组装、入库、出库、返工成功后清理上一笔扫码输入，避免下一笔作业误提交旧数据。
