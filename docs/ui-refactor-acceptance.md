## 已知环境问题

生产中心“异常隔离”Tab 可打开，读取 `GET /api/production/issues?page=1` 返回 HTTP 500，错误码 `SYSTEM_ERROR`，用户消息“系统暂时无法处理请求”。

本机后端日志 `tmp/public-runtime/server.out.log` 在 2026-09-30 16:14:37 记录 `ProductionMapper.xml` 查询抛出 MySQL 1267：`utf8mb4_general_ci` 与 `utf8mb4_unicode_ci` 在等值比较时冲突。查询涉及 `bike_vehicle.frame_sn = bike_production_issue.code`。独立直接读取相同接口也重现 500；本次没有修改对应后端、SQL、数据或请求。

前端展示真实错误及重试，没有伪装为空列表。这一子接口不能计入“所有 API 正常”。解决它需要单独授权后端/数据库范围，不属于本次仅表现层改造。
