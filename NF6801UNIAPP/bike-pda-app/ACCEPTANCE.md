# NF6801 真机验收清单

以下项目当前均需真机确认；自动化 mock 测试和原生资源编译不算通过本清单。

1. 安装与身份：核对 `com.bike.pda`、证书指纹、versionCode、arm64-v8a；冷启动正常，不出现 AppKey 校验错误，不打开任何网页。
2. 登录权限：普通账号与管理账号工位准确；强制改密、会话过期、退出、切换服务器和账号后的草稿隔离正常。
3. 组装：四码任意顺序、重复码、错误部件、未知车架、工单搜索、恢复/交接、完成、取消和总码均与后台一致。
4. 入库：启用仓库和库位可选；禁用库位不可选；码或选择变化后旧校验失效；重复入库受到服务端约束。
5. 订单出库：按客户选单、扫码跨码去重、剩余数量限制、错订单拒绝、提交结果与后台一致。
6. PI：多订单分配、队列恢复、整批提交、断网及超时使用原 requestId 重试，确认没有重复出库。
7. 返工追溯：车辆码与部件码不串字段；换件原因、库存状态和追溯履历完整。
8. 异常图片：登记隔离、拍照、相册、权限拒绝、20MB/20张限制、部分失败独立重试、后台图片完整。检查拍照返回/息屏恢复。
9. 硬件扫码：物理键和页面扫码按钮均有效；连续扫描、快速切页、前后台、息屏恢复不重复接收；手工输入仍可用。
10. 打印：正确纸宽、点数、DPI、黑标；中文、长字段、二维码、EAN13/UPCA 可实际扫出；不裁切、不乱走纸；缺纸/开盖/掉电不会误报成功。
11. 打印状态：同任务不能重发；领取冲突、发送超时、人工 SUBMITTED/FAILED/UNKNOWN、补打原因及新任务均正确。
12. 断网恢复：写入成功但响应丢失、进程被杀、切账号等场景先核对服务器，不自动重复提交。
13. 验收通过后再单独执行旧 PDA 网站下线；保留回滚方案，核实管理端反代的 API 不依赖 PDA 域名。

验收记录应注明设备型号、Android 版本、ABI、固件版本、纸张、操作账号角色、测试业务单号及实际结果，不记录密码或 token。
